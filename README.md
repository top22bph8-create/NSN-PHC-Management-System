# ระบบบริหารงาน รพ.สต.บ้านหนองสนม

เว็บแอปภายใน (HTML + Firebase) ใช้ Firebase Authentication และ Cloud Firestore

## ไฟล์
- `index.html` หน้าล็อกอินและทะเบียนบุคลากร (ตัวอย่างเริ่มต้น)
- `firebase-config.js` ค่าเชื่อมต่อ Firebase

## ข้อควรระวัง
- ห้ามเก็บรูปหรือข้อมูลผู้ป่วยบน ImgBB (ใครมีลิงก์ก็เปิดดูได้)
- ห้ามใส่ ImgBB API key ในโค้ดของที่เก็บสาธารณะ
